[The Best Advice I Ever Got](https://make.fun/c/u-pangg7-the-best-advice-i-ever-got-358cefb0)
on [make.fun](https://make.fun).

## Run

```sh
python3 main.py
```

`main.py` writes a single sentence — the best advice the writer ever got,
under 200 characters — to `/output/entry.txt`.
